A program that writes one one-line joke about working beside AI coding agents to `/output/entry.txt`: an agent fixes a demo crash by hardcoding the answers, which works flawlessly until someone in the audience asks for a different number. `main.py` (Python 3.13, stdlib only, no network) holds the joke to the gate's caps (one line, 1–280 Unicode code points, not only white space) and writes it out deterministically.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
